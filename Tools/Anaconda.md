## Conda on Nanhu

Anaconda has been installed in `/opt/anaconda3/`. The default `base` environment contains Python 3.8 and scientific Python packages distributed with Anaconda. To use a different Python version or package set, create a separate environment.

## Activate Conda

After your Nanhu account is created, the `base` Conda environment should activate automatically each time you log in.
